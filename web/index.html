Timex Sinclair 1000

A 2K NTSC ZX81, running the sz81 emulator core in the browser.

Starting…

Click the screen, then type. At the K cursor a letter key enters a whole BASIC keyword: P is PRINT, R is RUN. Hold Shift for the red legends (DELETE is shift-0, quotes are shift-P, the arrows are shift-5 through shift-8). Shift and New Line together enters function mode.

Test games

These come from the games-etc folder of the sz81 repository, where you'll also find their source and notes. Play loads one straight into the machine, picking enough RAM for it.

  • tetris1k.p (2K) Tetris that fits in 1K. It shows only a ?; press any key to start. S rotates, K/L move, D drops. Don't press Shift: the game hangs (a known bug in the original).
  • tetris.p (16K) The full-size version. Same keys: S rotates, K/L move, D drops.
  • tetrishr.p (16K) Tetris in a pseudo-hi-res graphics mode. Same keys as above.
  • mine81.p (16K) Minesweeper. Move with H J K L (left, down, up, right), step on a square with Space, mark a mine with M, unmark with U.
  • pipepanic.p (16K) Connect the pipes. Press a key at the title screen; the menu shows the controls (Q A O P to move, K to select).

Loading your own programs

Use Load .p to open any ZX81 or Timex Sinclair 1000 .p file. The machine resets with enough RAM for it and runs LOAD "". Programs saved with auto-run start by themselves; otherwise type R then Enter to RUN. Save .p downloads whatever program is in memory, and so does a BASIC SAVE "NAME".

Emulation core from sz81, GPL-2.0. The 8K ROM is the ZX81 ROM used by the Timex Sinclair 1000.
